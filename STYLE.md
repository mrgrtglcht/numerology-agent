# стиль quantafate

Согласовано пользователем: все надписи строчными, в том числе заголовки, начала предложений и quantafate; Manrope 500 для основного текста, 700 для заголовков; белый текст; затемнённые средневековые/готические фоны с окнами, плющом, туманом и приглушённой зеленью. Фон должен поддерживать текст, не перетягивая внимание. Кадрирование пропорциональное, без растяжения, с выбором фокуса.

Карусель кармического хвоста: без карт таро. Отдельный макет объясняет расположение хвоста на оригинальной схеме. Карты с прозрачными скруглениями предназначены для других тематических шаблонов. Продвижение бота добавлять лишь иногда и без вопросов: «разбор матрицы судьбы в telegram-боте quantafate».

Локальная реализация: `carousel.py`, пример `examples/15-5-8.json`, запуск `python agent.py carousel --batch style-15-5-8`. Получаются семь PNG 1080×1920, обзор, подпись, ZIP. Сборка не расходует запросы модели и не отправляет файлы наружу. Работает из папки проекта без временных файлов пользователя и без установленных системных шрифтов.

Схема на слайде 2 показывает расположение G2/G1/G (доли .66/.83/1 от центра по нижней вертикали), как в существующем matrix-bot. Это пример 15–5–8, а не рассчитанная личная матрица; остальные узлы намеренно без чисел. Не менять формулы matrix-bot ради оформления.

Фоны пользователя сохранены для просмотра макета. Основание для их публичного использования не установлено; не размещать их автоматически в публичном репозитории или сервисе. Новый `carousel-auto` ищет лицензированные изображения в Commons и передаёт Gemini реальные миниатюры для выбора фона, фокуса и написания нового текста одним запросом. Существующие `preview/draft/publish` по-прежнему используют старую схему трёх карточек.

Проверка локальной версии: 22 unittest пройдены; семь PNG собраны из настоящего результата поиска с демонстрационным текстом; схема проверена визуально. Живой тест Gemini учитывается отдельно от этого демонстрационного прогона. Buffer и Telegram для автоматической подготовки не используются.
