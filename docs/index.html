для чего создано приложение

quantafate publisher — внутренний инструмент владельца проекта quantafate. он помогает подбирать темы, готовить тексты и изображения для tiktok и pinterest, сохранять историю контента и избегать повторных публикаций.

ии используется для подготовки материалов. матрица судьбы и арканы рассматриваются как символические темы для размышления, без обещаний достоверного предсказания будущего.

публикации в облаке

контент-агент работает в github actions: готовит статьи для telegram-канала, чередует разборы матрицы и оракулы в tiktok, адаптирует разборы под квадратные карусели pinterest.

tiktok подключён через postwire с автодобавлением музыки. pinterest публикуется через upload-post с кликабельными ссылками в telegram. история тем, фонов и отправок помогает избегать повторов и продолжать подготовку после сбоев.
